# スナップショット Pro 運営管理

株式会社ダイトクの運営者向け管理画面です。

## 配信
Settings → Pages → Deploy from a branch → main / (root) を選びます。

## 本番に接続
管理画面の「本番に接続」で https://sp-shot.com/admin-api.php を指定し、ロリポップ側で登録した運営者アカウントを使用してください。会社用のアカウントとは別です。

このリポジトリに含まれるのは静的な管理画面と説明用サンプルです。顧客データ、DB設定、パスワード、APIトークン、PHPサーバーコードは含みません。本番データは運営者認証後にAPIから取得します。

使用量はMySQLに保存された会社別指示書JSON（画像を含む）のバイト数です。サーバー全体・バックアップの容量は含みません。上限設定は監視用で本体の保存制限には未連動です。
